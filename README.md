# Portfolio — Sanjith M

Personal portfolio site. Single self-contained `index.html` (no build step).

- **Stack:** plain HTML + CSS + a little vanilla JS
- **Fonts:** Bricolage Grotesque, IBM Plex Sans, IBM Plex Mono (Google Fonts)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy with GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → `main` / `root`.
